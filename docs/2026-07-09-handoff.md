## ✅ 오늘 완료 + 프로덕션 배포 (커밋 `fc8af0b`, 태그 `landscape-fs-solved-20260709`)

### 1. 가로 전체화면 배경 스크롤 (핵심, pointer 재설계) — `9da13d9`
- **진짜 원인**: 캔버스 `touch-action:none` + ontouchstart 항상 preventDefault → 네이티브 스크롤 원천차단. 수동스크롤은 게이트 false. + **핸들러가 캔버스에만 바인딩 → 캔버스 작을 때 배경터치가 레터박스(rm-canvas-area)에 떨어져 아예 안잡힘(=S 미표시 진범).**
- **해결**: rmBindEvents 터치핸들러는 rotate-fs서 **양보(bail)**. **denn-v33 블록(roomFrameHitTest 근처 L4166~)에 pointer 통합 핸들러 신규** — `document` capture(캔버스 밖도 잡음)+`roomFrameHitTest`로 액자/배경 구분. 액자=드래그+`setPointerCapture`(스크롤바 thumb L14622 검증패턴, 진행중 안풀림), 배경=수동 `area.scrollTop`. 헬퍼 `dennRoomLandFsActiveV`(L2239). CSS=rotate-fs rm-canvas-area `touch-action:none`(L14496). 제거=dennRoomLandTouchCtxV/dennTouchOnFrameV/__scrollDrag.

### 2. 액자 드래그 안 풀림 + 3. 배경 스와이프발 스케일 축소
- `setPointerCapture`로 드래그 진행중 브라우저에 안 뺏김. `__userMoved`는 **액자 드래그에만** 세팅(배경 스크롤은 RM.dragging=false 유지) → 거짓양성 근절.

### 4. 순수 회전 스케일 드리프트 — ②고치니 자동 해소
- 실측(진단오버레이): 운영자 `base.guideScale(73.5)≠.mobile.guideScale(49.5)`, L4448-4449가 방향전환 시 세로=.mobile/가로=base 재적용. 하지만 measureBase도 방향별로 달라 **상쇄→액자 시각크기 일관**. ①의 pointer재설계가 배경스와이프 오염 없애자 회전 깨끗해져 **사용자 "해결" 확인**(비독립 수용).

### 5. 가로 화질(블러) — dpr배 백킹 (검정 없이) — `a881fb7`+`ef315ca`
- **검정화면 결합의 진짜 정체 = `L13809(구 L13807) #room-modal #rm-canvas-area #rm-canvas{width:auto!important}`(특이도 3 IDs)가 rotate-fs 캔버스 표시크기를 백킹에 묶음** → 백킹 dpr배 올리면 표시까지 부풀어 오버플로우=검정. (이전 인라인!important 실패=특이도 전쟁 취약.)
- **해결**: 그 규칙을 **`html:not(.denn-rotate-fs)`로 rotate-fs 미매칭**(전쟁 제거) + V107 사이저(L14460) 백킹=`cw*min(dpr,4)`+표시 cw/ch 인라인!important + `imageSmoothingQuality='high'`. **검정 없이 선명화.** 한계=배경사진 원본해상도.

### 6. E. 새로고침 UI 잔상/튐 — 전역 부트 커버 — `fc8af0b`
