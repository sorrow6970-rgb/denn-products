## 원인

1. 저장된 업로드형 액자 템플릿 렌더에서 투명 오버레이로 판단되는 경우 안쪽 종이 배경을 생략해 프레임의 어두운 바탕이 비쳐 보일 수 있었다.
2. 투명 캔버스 템플릿 카드 CSS가 실제 썸네일 이미지를 숨기고 안내 문구만 표시해, 카드 미리보기와 실제 렌더가 다르게 보였다.
3. 고객용 카카오 문의 전용 패치가 기존 주문 저장 호출을 건너뛰어 어드민 주문의뢰 목록에 새 주문이 쌓이지 않았다.
4. `name`, `name2` 계열 텍스트 필드에 기존 20자 제한이 일부 남아 있었다.

## 수정 내용

- 저장된 업로드형 템플릿도 기존처럼 액자 안쪽 종이 면을 먼저 그리고 그 위에 투명 PNG 오버레이를 합성하도록 보정했다.
- 투명 캔버스 템플릿 카드에서 실제 썸네일 이미지를 표시하도록 CSS를 보정했다.
- 주문 모달의 `카카오채널로 시안 보내기` 흐름에서 기존 주문 저장 스키마를 유지해 `denn_order_requests`에 저장되도록 연결했다.
- 고객에게 고해상도 인쇄파일 다운로드는 다시 노출하지 않고, 시안 저장 후 카카오채팅을 여는 흐름은 유지했다.
- `name`, `name2`, `name3...` 계열 필드의 최대 길이를 30자로 보정했다.
