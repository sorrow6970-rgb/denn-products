## 터치/스크롤 WIP — 현재 코드와 남은 1건
**목표(사용자 확정):** 가로 전체화면서 ①액자 위 터치=드래그 ②배경 터치=상하 스크롤 ③햇빛 광원=이동, **3모드 명확 분리 + 매끄럽게.**

**구현(main HEAD, rmBindEvents 근처 L2237~ + 주입 CSS L14441):**
- 헬퍼 `dennRoomLandTouchCtxV()`(가로+스크롤여지 OR rotate-fs OR fsA), `dennTouchOnFrameV()`(RM.frameHit 히트테스트, pad 0.15), `dennTouchDbgV()`(임시 좌하단 진단).
- 캔버스 `touch-action:none`(가로 전체화면) → **액자 드래그 안 풀림(성공, 사용자 확인).**
- ontouchstart 3분기: 햇빛/액자(F,드래그)/배경(S,수동 스크롤 `area.scrollTop` 1:1 + 중앙유지루프 gen중단). ontouchmove `__scrollDrag` 분기. ontouchend/cancel 리셋.

**★남은 1건 = 배경 스크롤 안 됨.** 증상: 배경 스와이프 시 좌하단 진단표시(`S`)가 **아예 안 뜸** → `dennRoomLandTouchCtxV()`가 **false** 반환(모든 터치가 일반 드래그로 빠짐 → 액자만 됨). ★다음 세션 **첫 작업**: wip 채널 열고 배경 터치 → 좌하단 무조건표시(`iw.. ih.. sc.. rot.. fsA.. L.. F..`) 읽기 → **`L`(land 판정)이 왜 0인지 확정**:
- `sc`(area scrollHeight-clientHeight)가 ≤2면 → 캔버스가 그 순간 cover 안 됨(사이징 타이밍). `rot`/`fsA`도 0이면 클래스 미부여.
- 진단값 나오면 컨텍스트 판정을 그 실제 조건으로 교정 → 배경 S 모드 진입 → 스크롤. (수동 스크롤 자체는 이전에 동작 확인 필요 — scrollTop 되돌리는 다른 코드: 중앙유지루프 L14628[gen], V107 원샷 L14394[__dennRotCentered], 는 이미 차단함.)
- ★**임시 디버그(`dennTouchDbgV` 호출 3곳 + 함수 정의) 해결 후 반드시 제거.**

**대안(스크롤 계속 난항 시):** touch-action:pan-y(네이티브 스크롤=배경 확실히 됨)로 두고, 액자 드래그만 견고화. 단 pan-y면 액자 드래그 중 브라우저가 세로 제스처 가로채 "드래그 순간 풀림" 발생(오늘 확인). touchstart서 touch-action 동적변경은 진행 중 제스처에 안 먹힘(확인). → pan-y 유지하려면 프레임 드래그를 pointer이벤트+setPointerCapture로 전환 검토(스크롤바 thumb L14603이 이 방식으로 안 풀림).
