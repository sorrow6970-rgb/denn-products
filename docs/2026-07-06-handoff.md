### ★★핵심 교훈 — 검정의 진짜 원인
- **사이저가 2개**: 코어 `rmSizeCanvas` rotate-fs 블록(L3935, **contain**+dpr) vs v107 래퍼(L14367, **cover**+dpr없음). v107이 나중 실행→이김. **둘이 매 호출 서로 다른 크기로 리사이즈**.
- `d16530f`에서 dpr 백킹을 얹자 → 코어·래퍼가 **매 호출 backing 재설정(=canvas.width 재대입=clear) + 동기 rmRender** → clear↔render thrash → 에뮬레이터(타이밍 예민)서 **검정**.
- **rmRender(L2020~2022)는 `W=RM.canvas.width`(백킹) 공간에 그림** → 백킹 크기 바꾸면 clear됨. 백킹은 신중히.
- **결론: 브라우저별 패치(whack-a-mole)로는 최적화 안 됨. 사이저를 하나로 통합해야 함**(사용자 지적 정확).

### 레터박스 캡이 있던 2곳(둘 다 삭제해야 cover 됨)
- 정적 CSS `L3164~`: `html.denn-rotate-fs #rm-canvas-area{overflow:hidden}` + `#rm-canvas{max-width:100vw;max-height:100dvh}` — 삭제함.
- 주입 CSS `L14423`(v108 스타일 문자열): `#rm-canvas{max-width:100vw;max-height:100dvh;touch-action:none}` — 삭제함. **★단, `touch-action:none`(스크롤바전용 의도)이 캡과 한 줄에 묶여 있어 통째 삭제됨 → 캡만 빼고 touch-action:none은 되살려야 함**(현재 위 cover 규칙 L14414 `touch-action:pan-y`가 살아 터치스크롤이 켜졌을 수 있음).

## ▶ 다음 세션 = 단일 사이저 리팩터링 (브라우저 무관 통일)

**목표**: 어떤 브라우저(삼성/크롬/카카오/에뮬)든 가로 전체화면 = 동일 구도 + 선명 + 스크롤바 + 센터.

**설계**:
1. **진입조건 통일**: 가로 전체화면 판정을 `denn-rotate-fs` 단독이 아니라 **`denn-rotate-fs || (room-modal.denn-room-fullscreen-active && innerWidth>innerHeight)`** 로(옛 `__dennRmFsLand` 방식 부활). 사이징·스크롤바 토글(L14587)·CSS 셀렉터 **모두 이 통일조건 기준**으로 → 카카오도 같은 경로.
2. **사이저 1개로**: 코어 `rmSizeCanvas` rotate-fs 블록을 **유일 사이저**로 만들고 v107 래퍼의 경쟁 사이징(L14367-14373) **제거**(센터로직만 남김). 코어에서:
   - **cover**(폭 채움: `cw=vw, ch=vw/ar`; ar=`__dennLsArV` 고정 랜드스케이프 비율),
   - **백킹=cw×dpr**(선명), **표시크기 `setProperty('width',cw,'important')`**(L13720 `width:auto!important` 이기게),
   - 사이저 1개라 **매 호출 clear 경쟁 없음 → 검정 재발 안 함**(동기 rmRender 불필요, 정상 flow가 렌더).
3. **CSS**: 캡은 이미 제거됨. `touch-action:none`(스크롤바전용) **되살리되 max-height 캡과 분리**해서 단독 규칙으로.
4. **검증**: 반드시 **카카오 실기기**로 — 화질/레터박스/스크롤바 3개 동시 확인. `?dbgUM=1`/`?debug=1` 온스크린 오버레이 활용(rotFS 클래스 여부·cvRect·dpr 찍기).

**리스크/주의**:
- 코어 `rmSizeCanvas`는 공유 함수(세로/PC/촬영배경도 씀). rotate-fs 분기 안에서만 손대고 다른 분기 무영향 확인.
- 회전 왕복(가로↔세로) 시 `__dennRotCentered`/`__dennRotPLockV`/`dennRotCenterLoopV`(L14603) 센터·떨림 로직 건드리지 말 것(과거 다수 회귀).
- 큰 변경 전 **known-good(`23a1ebb`) 태그/백업**. 미커밋 즉시 커밋(롤백 유실 사고 이력).
