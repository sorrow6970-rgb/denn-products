## 2. 각 결정이 확정하는 것

### 2.1 P-1 — 액자만, 케이스는 별도 스펙

- 레거시 케이스 인쇄는 **V36 구경로**이고 텍스트도 `textObjs`(스펙 031 F-1로 이미 범위 밖)라
  텍스트 모델이 다르다(조사 §1·§3.2).
- 액자만 하면 스펙 029(normalized pan)·030(quarter turn)·031(확정 텍스트) 계약을 **그대로 재사용**한다.
- **케이스 인쇄는 별도 스펙**이며, 그 스펙이 열리기 전까지 케이스 인쇄 코드를 만들지 않는다.

### 2.2 P-2 — 물리 치수는 명시 필드에서만

- 레거시의 `frameCm`(필드 8종 → **이름 텍스트 파싱** → 하드코딩 표, 조사 §2.3)은 **재현하지 않는다**.
  사이즈 **이름을 바꾸면 인쇄 해상도가 바뀌는 동작은 제품 사고**다.
- 후보 필드에 `w/h`가 있어 **논리 px를 cm로 오해**할 수 있었던 문제도 함께 제거된다.
- **전제**: 카탈로그 V1 `frameSizes` allowlist(`packages/shared/src/catalog/read.ts:82`)에는
  **cm 필드가 없다**. 따라서 **카탈로그 스키마 확장이 필요**하고, 값을 입력할 **운영자 UI는
  `apps/admin/**` 이므로 별도 스펙**이 동반된다(조사 STOP 4).
- **치수가 없는 사이즈는 인쇄를 만들지 않는다**(P-3과 같은 fail-closed). 추측하지 않는다.

### 2.3 P-3 — 경고가 있으면 인쇄 파일을 만들지 않는다

- 레거시는 템플릿 아트 로드 실패를 `warnings` 문자열로만 남기고 **아트가 빠진 PNG를 반환**해
  저장·다운로드·카카오까지 진행했다(조사 §5).
- 미리보기는 스펙 026/028/031에서 이미 **fail-closed**다. **인쇄도 동일**하게 맞춘다.
- 즉 **부분 인쇄 파일·경고 동반 파일을 생성하지 않는다.** 실패는 실패로 끝난다.

### 2.4 P-4a — 임시값으로 구현하되 출력은 차단

- `300dpi` · `minLongSide 3000` · `maxPixels 36,000,000` · `fallbackLongSide 3508`은
  **레거시 관측값일 뿐 인쇄소 요구로 확인된 바 없다**(조사 §12 NOT VERIFIED).
- 이 값들을 **명시적 임시값으로 표시**해 구현·유닛·E2E까지 진행한다. 좌표·wrap·회전 계약의 정합성은
  수치와 무관하게 검증할 수 있고, 수치는 나중에 상수만 바꾸면 된다.
- **★ 차단 조건(배포 전 게이트)**: **인쇄소 확인 전까지 실제 인쇄 파일의 업로드·주문 전송·배포를
  금지**한다. 로컬 다운로드와 E2E는 허용한다.
- **함께 받아야 할 미확인 항목**: **색공간/ICC · 재단 여백(bleed)·안전선 · 파일 형식 · 최대 파일 크기**
  (현재 저장소 근거 0).

### 2.5 P-5 — 세 데이터를 분리해 확정

| 데이터 | 결정 | 내용 |
| --- | --- | --- |
| 색 · 사진 transform(scale·pan·quarter turn) | **P-5a 담는다** | 비개인 설정값. 재현·재인쇄에 필요하다 |
| 시계 유무(`clockOn`) | **P-5b 담는다** | 비개인 **제품 구성**. 실물 시계 부착 여부는 운영자가 알아야 하는데 지금 주문서에 없다 |
| 고객 문구 원문(`main`/`name`/`name2`/`date`/`sub`) | **P-5c 제외** | **텍스트로 저장하지도 전송하지도 않는다** |

**P-5c의 의미**: 문구는 **이미 인쇄 PNG에 픽셀로 들어가 있으므로** 주문 처리에 추가 저장이 필요 없다.
텍스트로 별도 저장·전송하려면 **개인정보 처리방침·보존 기간·삭제 절차에 대한 별도 승인**이 필요하며
**이 스펙의 범위가 아니다**. 이는 스펙 031의 "오류 payload에 고객 원문을 넣지 않는다" 규율을
**저장·전송 경로까지 일관되게 확장**한 것이다.

### 2.6 P-6 — 줄바꿈은 반드시 동일

- 고객이 승인한 화면과 인쇄물의 줄바꿈이 다르면 **본 것과 받는 것이 달라진다**.
- 이 결정은 조사 §8.1의 후보 선택을 **제약**한다: 어떤 후보를 택하든 **줄바꿈 동일성을 구조적으로
  보장**해야 한다. 재측정으로 "대체로 같음"에 기대는 방식은 허용되지 않는다.
- **단, 후보 A/B/C 중 어느 것을 택할지는 Codex 결정(C-1)이며 이 문서가 정하지 않는다.**

## 3. 이 결정이 만드는 불변식

1. **케이스 인쇄 코드를 만들지 않는다**(별도 스펙 전까지).
2. **인쇄 치수를 이름·텍스트에서 추측하지 않는다.** 명시 필드가 없으면 **인쇄를 만들지 않는다**.
3. **경고가 있으면 인쇄 파일이 존재하지 않는다.** 부분 파일·아트 누락 파일 **0**.
4. 해상도 수치는 **임시값**이며, **인쇄소 확인 전 업로드·주문 전송·배포는 차단**된다.
5. **고객 문구는 텍스트로 저장·전송되지 않는다.** 비개인 항목만 주문 payload에 담는다.
6. **미리보기와 인쇄의 줄바꿈은 동일**하다.
7. 스펙 019 geometry · 026 image owner · 028 art · 029 pan · 030 rotation · 031 text/clock 계약은
   **무변경**이며, 시계는 인쇄에 **들어가지 않는다**(031 F-4).
