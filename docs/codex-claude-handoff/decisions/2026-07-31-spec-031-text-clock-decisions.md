## 1. ★ F-4 — 시계의 제품 의미 (가장 중요한 결정)

> **Founder 결정: 시계는 "완제품의 물리적 시계 하드웨어 미리보기"다.**

조사 §3.5.1에서 `UNCONFIRMED`로 남겼던 항목이 **Founder 권한으로 확정**됐다. 저장소에는 확정 근거가
없었고 Codex도 임의 선택하지 않았다.

### 1.1 이 결정이 즉시 확정하는 것

| 항목 | 확정 내용 |
| --- | --- |
| **print/export** | 시계를 **포함하지 않는다**. **현행 동작이 곧 정답**이다 — 레거시 인쇄 경로가 시계를 빼 온 것은 결함이 아니라 **의도된 동작**이었다 |
| **"미리보기≠인쇄"** | **문제가 아니다.** 조사 보완 라운드 1에서 이미 철회한 판정이 최종 확정됐다 |
| **F-5(인쇄 시각의 의미)** | **불필요**(F-4b일 때만 필요한 결정이었다). 고정 시각·주문 시각 논의는 **하지 않는다** |
| **`packages/render` 계약** | **시계 때문에는 바꾸지 않는다.** 텍스트(`textZones`) 때문에만 확장한다 |
| **결정적 plan** | 시계는 **plan에 담지 않는다.** print/export와 공유할 결정적 plan을 **전제하지 않는다** |
| **`draw-text`의 시각 확정** | **불필요**. 시계는 plan 밖의 preview overlay다 |

### 1.2 시계 구현의 실제 범위 (조사 §8.4 ⓐ 갈래)

**preview overlay 계약 + timer lifecycle만** 다룬다.

1. 오버레이를 **캔버스에 굽지 않고 DOM 오버레이로 분리**할지 결정한다 — 이 저장소에 **선례가 있다**
   (운영자 가이드 이미지, `docs/denn-v36.4-frame-template-tools-report.md:60`).
   미리보기 전용이라는 성격상 **분리를 권장**하되 최종 구조는 Codex 계약으로 확정한다.
2. **1초 갱신이 실제로 필요한지** 판정한다(정지 시계로 충분한지).
3. **타이머가 정확히 하나만 살아 있는지** 보장한다 — 언마운트·템플릿 전환·토글·StrictMode 재마운트.
   레거시의 누수(조사 §3.3: `clockTmr` 덮어쓰기 전 `clearInterval` 없음)를 **재현하지 않는다**.
4. 시계가 **실물로 부착된다는 사실을 고객에게 알리는 문구**가 필요한지 결정한다(후속 UX 항목).

### 1.3 조사에서 유지되는 사실

- 운영자 데이터 3단 병합(`ADM.clockSettings` → `frameSizes[].clock` → `frameTemplates[].clock`),
  필드 `{x, y, size, customImg}` — **위치 데이터의 의미가 "실물 시계가 붙는 자리"** 로 확정됐다.
- 그래서 운영자 빌더가 그것을 **"⏰ 템플릿용 시계 가이드"**(`admin:335`)라 부르고
  **"템플릿 제작 시 시계를 미리 보면서 위치를 잡고"**(`admin:342`) 안내한 것이 문자 그대로의 의미였다.
- `clockOn`이 `space-scene-v1`의 `design`에 저장되는 것(`mockup:15636`)은 **시계 하드웨어를 포함한
  제품 구성**을 씬이 재현하기 위함으로 해석한다. 공유 씬 계약은 **바꾸지 않는다**.

## 2. Founder 승인 — 텍스트 권장 묶음 (일괄 승인)

| ID | 결정 | 승인 내용 |
| --- | --- | --- |
| **F-1** | 텍스트 모델 범위 | **1차는 액자 key 기반 `textZones`만** 구현한다. 케이스 자유 배치 텍스트(`textObjs`)는 **별도 스펙**으로 미룬다 |
| **F-2** | 고객 색·그림자 오버라이드 | **1차 미지원.** 운영자 zone 스타일을 **단일 정본**으로 사용한다 |
| **F-3** | 운영자 `defaultTexts` | **값으로 자동 입력하지 않는다.** **placeholder로만** 표시한다 |
| **F-6** | 문구 길이 상한 | **zone별 길이 상한을 계약 필드로** 두고 **초과 입력을 차단**한다. **자르기·말줄임·자동복구 없음** |
| **F-7** | 줄 수 상한 | **zone별 줄 수 상한, 기본 2줄**로 통일한다 |
| **F-8** | 다섯 키 처리 | 고객 측 `main`/`name`/`name2`/`date`/`sub`를 **균일 처리**하되 **`name2` 기본값은 만들지 않는다.** admin 편집기 확장은 **별도 스펙** |

### 승인 근거 요약

- **F-1**: 두 모델은 코드도 데이터도 공유하지 않는다(조사 §1). 자유 배치는 드래그·선택·히트테스트·삭제
  UI가 따로 필요하고, 스펙 029가 이미 도입한 **사진 드래그와 제스처가 충돌**할 수 있다.
- **F-2**: 레거시의 `applyFrameTextStyle` 오버라이드가 zone 색을 가로채 **기본 글자색이 `#111`↔`#FFF`로
  뒤집히는 결함**(조사 §2.4)의 원인이었다. 소유자를 하나로 닫는다.
- **F-3**: 초기값으로 넣으면 운영자 샘플(`'WEDDING'`, `'J & K'`, `'11 MAY 2025'` — `admin:1728`)이
  **그대로 인쇄물에 들어간다**(조사 §5).
- **F-6 / F-7**: 레거시는 wrap 경로마다 줄 수 상한이 **2 또는 3으로 어긋나** 미리보기와 인쇄가 달랐다
  (조사 §2.2). 상한을 계약으로 올리고 **입력 단계에서 차단**하면 그 divergence가 원천 제거된다.
  조용한 잘림·말줄임은 "본 것과 다른 인쇄물"을 만들므로 **금지**한다 — 스펙 029/030의
  **"거부하되 복구하지 않는다"** 규율과 동일하다.
- **F-8**: 고객 입력은 5개인데 운영자 `defaultTexts`는 4개뿐이라 `name2`만 기본값을 가질 수 없다
  (조사 §1.1). 리빌드 고객 측은 균일하게 처리하고, 운영자 편집기 수정은 `apps/admin/**` 범위라
  이번 스펙 밖이다.

## 3. 이 결정이 만드는 불변식

1. **시계는 인쇄물에 들어가지 않는다.** print/export 경로에 시계를 추가하지 않는다.
2. **시계는 결정적 plan에 담기지 않는다.** `packages/render` plan 어휘는 시계 때문에 확장되지 않는다.
3. **텍스트는 plan에 담긴다** — 미리보기와 인쇄가 같은 plan을 소비한다(조사 C-1: wrap을 **plan 생성
   시점에 확정**).
4. **케이스 텍스트는 이번 범위가 아니다.** 액자 `textZones` 하나의 모델만 구현한다.
5. **텍스트 스타일의 소유자는 운영자 하나다.** 고객은 값만 입력한다.
6. **운영자 샘플 문구가 고객 값이 되지 않는다.**
7. **길이·줄 수 초과는 입력 단계에서 차단**되며, 잘라내거나 말줄임하거나 자동 복구하지 않는다.
8. 스펙 019 geometry · 026 image owner · 028 template art · 030 rotation 계약은 **무변경**이다.

## 4. 이 결정에 포함되지 않은 것 (여전히 미결정·미검증)

- **케이스 자유 배치 텍스트**(F-1로 분리) → 별도 스펙
- **admin 편집기의 `name2` 기본값 지원**(F-8로 분리) → 별도 스펙(`apps/admin/**`)
- **고객 색·그림자 오버라이드**(F-2로 1차 제외)의 향후 도입 여부
- 시계 오버레이를 **DOM 분리할지 캔버스에 그릴지**의 최종 구조 → Codex 계약 결정
- **1초 갱신이 필요한지**(정지 시계 가능성) → Codex 계약 결정
- 시계가 실물임을 알리는 **고객 안내 문구** 필요 여부 → 후속 UX 결정
- zone별 **길이·줄 수 상한의 구체적 값**과 그 저장 위치(카탈로그 vs 계약 기본값) → Codex 계약 결정
- 조사 C-1~C-7·C-9~C-11(wrap 측정 포트, `draw-text` 형태, 폰트 스펙, letter-spacing, 회전, clip,
  빈 값, executor capability, 오류 우선순위, 투영)은 **Codex가 확정**한다
- 실기기 IME·소프트 키보드·폰트 대체·실제 인쇄물 가독성은 **NOT TESTED**로 남는다
