# Modern Studio 웜 토프 팔레트 결정

상태: **확정 · 2026-07-22 사용자 최종 결정**

## 결정

Modern Studio(B)의 포인트 팔레트를 카라멜 앰버에서 다음 웜 토프로 교체한다.

| 토큰 | 값 |
|---|---|
| `accent` | `#9F887A` |
| `accent-2` | `#BAA598` |
| `accent-soft` | `#EEE8E1` |
| `accent-ink` | `#191A1D` |
| `kakao` | `#FEE500` (텍스트 `#191600`) |

이 결정은 이전 `2026-07-21-caramel-amber-palette.md`를 역사 기록으로 보존하면서, 신규 구현에 대해서는 이를 대체한다.

## 접근성 근거

- 흰색 / `accent #9F887A`: 약 **3.35:1** — 일반 텍스트 AA 미달.
- `ink #191A1D` / `accent #9F887A`: 약 **5.20:1** — 일반 텍스트 AA 통과.
- 흰색 / `accent-2 #BAA598`: 약 **2.35:1** — 일반 텍스트에 부적합.
- `accent` / `accent-soft #EEE8E1`: 약 **2.75:1** — 일반 텍스트와 필수 UI 경계에 부적합.

따라서 포인트색을 확정하더라도 흰색 라벨을 일반 텍스트로 사용하지 않는다. primary·활성 chip의 라벨은 `accent-ink`, accent-soft 위 라벨·아이콘은 `ink`를 사용한다. 색만으로 상태를 전달하지 않는다.

## 변경 규칙

- 디자인 토큰을 통해 교체하며 컴포넌트 내부에 색상 리터럴을 분산시키지 않는다.
- 이전 카라멜 앰버 스펙 004·005와 실기기 결과는 당시 검증 이력으로 수정하지 않는다.
- POC 코드·CSS·명암비 테스트·자동검증·실기기 표시는 새 스펙에서 다시 검증한다.
- 시안 PNG는 참고 자료다. PNG 안의 텍스트 대비가 이 결정과 충돌하면 토큰과 접근성 계약을 우선한다.
- 카카오 브랜드 색상은 변경하지 않는다.
