# 검증된 스펙 변경의 원격 전송 승인

2026-09-07. 사용자는 직전 질문에 `응 승인할게,`로 답했다.

## 승인한 전송 범위

- 스펙093의 `1e322c1`(시험 전용 코드·합성 증거)와 `cfb1a32`(종료 문서).
- 이후 합의된 스펙 범위의 검증된 코드·합성 증거·상태 문서와 그 승인/완료 기록.
- 정확한 대상: `https://github.com/sorrow6970-rgb/denn-products.git`의 `rebuild/modern-studio`.
- 일반 fast-forward push만 허용한다. 범위·검증·변경 파일 확인을 통과한 경우 전송마다 재확인하지 않는다.

이는 위 저장소로 해당 개발 산출물을 전송하는 승인이지 새로운 제품 결정이나 운영 배포 승인이 아니다.
다른 원격·브랜치 또는 위 범위를 벗어나는 데이터의 전송 승인은 포함하지 않는다.

## 계속 제외되는 범위

보호 파일, 실제 운영 데이터·secret·실제 UID, Rules/Hosting 배포, 운영 쓰기·발행·삭제·자동 정리,
force push/merge/rebase/reset 및 신규 의존성·실제 Firebase 접근은 기존 금지 정책을 유지한다.
이미 dirty인 별도 사용자 작업을 묶어서 전송하지 않는다. 예약 자동화·반복 작업도 만들지 않는다.

스펙은 코드 전에 작성하고, 결정 충돌·새 권한·범위 밖 변경·원인 불명 실패·도구의 권한 거절이 생기면
중단한다. 이 승인은 권한 거절을 우회하는 허가가 아니다. 직접 구현·검토는 독립 검수로 표시하지 않는다.

근거: 이 대화의 직전 구체적 대상/변경 종류를 명시한 전송 질문과 사용자 승인 응답.
