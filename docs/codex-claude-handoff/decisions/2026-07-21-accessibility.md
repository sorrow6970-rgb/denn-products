# 결정: 접근성 정책

결정일: 2026-07-21

상태: **확정 · UI 출시 차단 조건**

## 핵심 결정

> WCAG 2.2 AA를 목표로 한다. 키보드·터치·200% 확대·VoiceOver/TalkBack에서 핵심 편집과 저장·주문 흐름을 사용할 수 있어야 하며, Canvas 기능에는 DOM 상태와 대체 조작을 제공한다.

## 1. 키보드

- 키보드만으로 내비게이션, 선택, 업로드, 입력, 모달, 저장·게시·주문을 수행할 수 있어야 한다.
- 논리적인 Tab 순서를 유지한다.
- 숨은 요소로 포커스가 이동하지 않는다.
- 클릭 가능한 `div` 대신 의미에 맞는 HTML 요소를 사용한다.
- 커스텀 조작에는 표준 키보드 패턴을 제공한다.

## 2. 포커스

- 대체 없는 `outline:none` 금지
- 명확한 `focus-visible`
- 모달 진입·트랩·닫은 후 복귀
- 오류 요약 또는 오류 필드 포커스
- 라우트 전환 후 제목·주요 영역 포커스 관리

## 3. 색상·명암비

- 일반 텍스트 4.5:1 이상
- 큰 텍스트 3:1 이상
- UI 경계·아이콘 3:1 이상
- 색상만으로 상태 표현 금지
- Modern Studio 테라코타와 흰 글자 조합을 실제 계산하고 필요 시 토큰 조정
- 카카오 브랜드 색상도 명암비 검증

## 4. 확대·텍스트

- 브라우저 확대 200%에서 핵심 기능 유지
- OS 글꼴 확대 대응
- 고정 높이로 텍스트 자르기 금지
- 말줄임 전체 내용 확인 수단
- 모바일 입력 글꼴 크기 확보
- 한국어 줄바꿈과 긴 이름 대응

## 5. 터치

- 주요 터치 영역 최소 44×44 CSS px
- 인접 버튼 오조작 방지
- drag·pinch만으로 가능한 필수 기능 금지
- 드래그에는 버튼·키보드·숫자 입력 등 대체 수단 제공
- 취소와 되돌리기 제공

## 6. 폼

- 모든 입력에 연결된 label
- placeholder를 label로 대체 금지
- 필수·선택 표시
- 오류 이유와 수정 방법
- 오류 메시지와 필드 연결
- 실패 후 사용자 입력 유지
- 중요 제출 결과 확인
- 적절한 autocomplete 속성

## 7. 이미지·아이콘

- 의미 있는 이미지 대체 텍스트
- 장식 이미지는 보조기술 제외
- 아이콘 버튼 접근 가능한 이름
- 스와치의 색 이름
- 템플릿 이름과 선택 상태
- 업로드 상태의 텍스트 알림

## 8. Canvas

- 선택 사이즈·템플릿·색상·문구를 DOM으로 제공
- Canvas 조작의 대체 컨트롤
- 선택·위치·크기 상태 확인 수단
- 생성 상태 live region
- 실패 시 대체 오류 안내
- 주문 정보는 Canvas 밖에서도 확인 가능
- 최소한 업로드·기본 배치·텍스트·저장·주문 흐름은 보조기술로 완료 가능

## 9. 모달·알림

- 올바른 dialog 역할·제목
- 배경 콘텐츠 비활성
- Escape 닫기와 데이터 손실 확인
- 중요한 오류를 toast로만 전달 금지
- 성공·오류·저장 상태 live region
- 사라지는 메시지 재확인 수단

## 10. 움직임

- `prefers-reduced-motion` 지원
- 비필수 애니메이션 축소
- 깜빡임·과도한 반복 움직임 금지
- 애니메이션 완료 의존 조작 금지

## 11. 문서 구조

- 페이지 제목, 올바른 heading 순서와 landmark
- 현재 내비게이션 위치
- 표준 tab 또는 내비게이션 패턴
- 테이블 헤더 관계
- 시각 순서와 DOM 읽기 순서 일치

## 12. 언어

- 기본 문서 언어 `ko`
- 자연스러운 한국어 오류 안내
- 날짜·시간·단위 일관성
- 축약어나 아이콘만으로 기능 표현 금지

## 13. 검증

자동: axe, 명암비, 접근 가능한 이름, label, landmark, heading, 포커스 가능 여부.

수동: 키보드 핵심 E2E, 200% 확대, OS 글꼴 확대, VoiceOver/TalkBack 주요 흐름, reduced motion, 모달 포커스, Canvas 대체 조작.

자동 검사만으로 완료를 선언하지 않는다.

## 14. 출시 차단

- 키보드로 주요 CTA 접근 불가
- 포커스 손실·고립
- 모달 닫기 불가
- label·오류 안내 누락
- 주요 명암비 미달
- 200% 확대 사용 불가
- 보조기술에서 저장·주문 결과 확인 불가
- 필수 기능이 drag에만 의존
- 글꼴 확대 시 버튼·텍스트 잘림

## Claude Code 반영 지시

Claude Code는 이 결정서를 `CLAUDE.md`와 모든 UI 스펙의 강제 접근성 기준으로 참조한다. 자동 검사 결과만으로 접근성 완료를 보고하지 않는다.
