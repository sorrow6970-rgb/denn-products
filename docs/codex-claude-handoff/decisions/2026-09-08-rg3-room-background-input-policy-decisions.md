# RG-3 — 룸 배경 입력정책 승인

2026-09-08. Founder의 최신 대화 `승인하고 계약 검증 해줘`는 직전 RG-3=A 제안의 승인이다.
[103 선택지](../reviews/2026-09-08-spec-103-room-background-input-policy-investigation.md)의 A를 채택하고 B는 채택하지 않는다.

## 승인된 제품 방향

- 첫 룸 배경 형식은 정적 JPEG/JPG·PNG다. GIF/APNG/WebP/HEIC/SVG 등 추가 형식은 제외한다.
- 파일은 20,000,000 bytes 이하, 이미지 면적은 40,000,000 pixels 이하. 경계값을 포함한다.
  20×1,000,000 bytes, 40×1,000,000 pixels로 단위를 정확화했다.
- 초과·미지원·검증 불가 입력은 명시적으로 거부한다. 자동 형식변환이나 초과 원본 자동축소로 통과시키지 않는다.
- 이미 허용된 입력을 화면용으로 축소하는 것은 별도 단계다. 원본 변경·저장 승인이 아니다.

기존 [성능 결정 §4/5](2026-07-21-performance-and-resource-budgets.md)를 룸 입력에 정확화한 결정이며,
실기기 메모리 안전성·각 변의 기기별 상한·동시 decode 한도가 검증됐다는 뜻은 아니다.
