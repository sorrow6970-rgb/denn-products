# 결정: 성능 예산 및 리소스 관리 정책

결정일: 2026-07-21

상태: **확정 · 성능 회귀 차단 조건**

## 핵심 결정

> 모바일 Web Vitals와 번들·이미지·Canvas·저장소·listener·timer에 수치 예산을 둔다. 고해상도 인쇄는 화면 렌더와 분리하며, 예산을 초과한 변경은 근거와 승인 없이 병합하지 않는다.

## 1. 사용자 성능 목표

- LCP 2.5초 이하
- INP 200ms 이하
- CLS 0.1 이하
- 50ms 이상 장기 작업 최소화
- 조작 후 시각 반응 100ms 이내
- 일반 화면 전환 300ms 이내 체감
- 느린 작업에 진행 상태와 필요한 취소·복구 제공

모바일 제한 조건과 반복 측정 결과를 사용한다.

## 2. 초기 번들 예산(gzip)

- 고객 초기 JavaScript: 250KB
- 관리자 초기 JavaScript: 350KB
- 화면별 lazy chunk: 150KB
- 초기 CSS: 75KB

관리자·에디터·인쇄·룸·시안·주문 등 초기 화면에 필요 없는 기능은 지연 로드한다. 초과는 측정 근거와 사용자 승인을 요구한다.

## 3. 코드 분할

고객 첫 화면에서 관리자 코드를 내려받지 않는다. Zone Editor, 인쇄 export, 룸, 암호화, Firebase 관리, 주문, 비활성 케이스 기능은 사용 시점에 로드한다.

## 4. 이미지 예산

- 파일 크기와 실제 픽셀 수를 모두 검사한다.
- 업로드 파일 상한은 초기 최대 20MB로 둔다.
- 초기 이미지 픽셀 상한은 40MP로 두고 실제 샘플 검증 후 조정한다.
- 화면용 긴 변은 통상 2048–2560px 이내로 다운샘플한다.
- 프리뷰·썸네일·인쇄 원본을 목적별로 분리한다.
- base64 중복 복제 금지, Object URL과 이미지 참조 정리 의무화.

## 5. Canvas 예산

- CSS 크기와 backing-store 해상도를 분리한다.
- 인터랙티브 DPR 초기 상한은 2로 둔다.
- 일반 프리뷰 Canvas는 약 8MP 이하를 목표로 한다.
- 인쇄 Canvas는 제품 정확도를 우선하되 약 16MP 이상에서 기기 메모리를 검사한다.
- 화면 렌더와 인쇄 렌더를 분리한다.
- 고해상도 작업이 1초 이상이면 진행 상태를 표시한다.
- 처리 불가능한 크기는 크래시 대신 명시적 오류로 중단한다.

## 6. 렌더·이벤트

- 동일 프레임 중복 렌더 병합
- 연속 입력은 rAF 또는 검증된 throttle 사용
- resize·scroll의 동기식 대형 계산 금지
- 레이아웃 읽기·쓰기 분리
- 불필요한 전체 UI 재렌더 방지
- 백그라운드 탭의 불필요한 렌더 중단

## 7. Timer·listener

- 해제 시 timer, listener, observer 정리
- 무기한 polling 금지
- 동일 이벤트 중복 등록 차단
- 전역 listener 단일 소유
- visibility-aware 실행 우선
- 반복 마운트 후 리소스 증가 테스트

## 8. 저장소 예산

- localStorage에는 소형 설정·식별자만 저장한다.
- localStorage 전체 앱 데이터 500KB 이하를 목표로 한다.
- 단일 localStorage 값 100KB 이하를 목표로 한다.
- base64와 대형 카탈로그를 localStorage에 저장하지 않는다.
- IndexedDB·Storage 역할을 분리한다.
- 모든 캐시는 크기·개수·만료·eviction 정책을 가진다.

## 9. 네트워크

- 중복 요청 병합과 가능한 요청 취소
- 목록 pagination·제한 조회
- 전체 데이터 반복 다운로드 금지
- 이미지 캐시·버전 정책
- 업로드 진행률·실패 복구
- 오프라인·느린 연결 상태 표시

## 10. 메모리 반복 검사

- 이미지 교체 20회
- 템플릿 전환 50회
- 모달 30회
- 전체화면 20회
- 회전 반복
- 관리자 탭 반복
- 시안 열기·닫기

반복 후 listener, timer, Canvas, 이미지 객체가 지속 증가하면 병합하지 않는다.

## 11. 완료 증거

- 측정 환경·viewport
- 변경 전후 수치
- 번들 크기
- Web Vitals
- Canvas 렌더·export 시간
- 메모리 반복 결과
- 느린 네트워크 결과
- 초과 항목과 승인 근거

## 12. 예외

인쇄 정확성처럼 별도 성능 예산이 필요한 작업은 UI를 차단하지 않고 진행 상태·취소·실패 복구를 제공해야 한다.
