# 결정: 오류 처리·로그·운영 관측 정책

결정일: 2026-07-21

상태: **확정 · 전체 애플리케이션 필수 계약**

## 핵심 결정

> 빈 catch와 실패 은폐를 금지한다. 안정적인 오류 코드·구조 로그·correlation ID를 사용하고 민감정보는 수집하지 않는다. 저장·업로드·게시 결과를 확인하기 전에는 성공으로 표시하지 않는다.

## 1. 오류 분류

- `VALIDATION`: 입력·스키마 검증
- `AUTH`: 인증·세션·권한
- `NETWORK`: 오프라인·타임아웃·통신
- `STORAGE`: localStorage·IndexedDB·Firebase 저장
- `UPLOAD`: 이미지 검사·업로드·다운로드
- `MIGRATION`: 구버전 데이터 변환
- `RENDER`: Canvas·이미지·인쇄
- `SPACE`: 시안 암·복호화·토큰
- `ORDER`: 주문 생성·저장·다운로드
- `UNKNOWN`: 예상하지 못한 오류

오류는 안정적인 코드, 카테고리, 사용자 메시지, 재시도 가능 여부, correlation ID를 포함한다. 사용자 메시지와 내부 원인을 분리한다.

## 2. 실패 은폐 금지

- 빈 `catch`를 금지한다.
- 오류는 상위 전달, 사용자 표시, 안전한 fallback, 제한된 재시도 또는 진단 기록 중 하나로 명시적으로 처리한다.
- fallback이 성공해도 원래 실패를 진단 가능하게 남긴다.
- 실패를 기본값으로 덮어 정상처럼 진행하지 않는다.

## 3. 성공 판정

다음을 실제 확인하기 전 성공을 표시하지 않는다.

- 저장 트랜잭션 완료
- 업로드 후 다운로드 가능
- 게시 데이터 재조회 가능
- 마이그레이션 검증 완료
- Canvas 출력 Blob과 크기 정상
- 주문 데이터 저장 확인

Promise 생성이나 요청 시작은 성공이 아니다.

## 4. 사용자 안내

오류 메시지는 실패한 작업, 데이터 보존 여부, 재시도 가능성, 사용자가 할 행동, 필요 시 오류 ID를 포함한다. 내부 stack trace와 Firebase 상세 오류는 사용자에게 노출하지 않는다.

## 5. 재시도

- 재시도 가능한 네트워크 오류만 자동 재시도한다.
- 지수 backoff와 최대 횟수를 둔다.
- 인증·권한·검증 오류는 자동 재시도하지 않는다.
- 중복 제출을 차단한다.
- 주문·게시·시안 생성의 멱등성을 보장한다.
- 무한 폴링·무한 타이머를 금지한다.

## 6. 구조 로그

로그는 level, code, correlationId, feature, environment, appVersion, timestamp를 포함하는 구조를 사용한다.

기록 금지:

- 비밀번호와 인증 토큰
- 시안 토큰 전체
- 고객 이름·연락처·메모
- 이미지·base64
- 전체 상태 객체
- 암호화 전 시안 데이터

## 7. 환경별 로그

- local: 상세 진단 가능, 민감정보 금지는 동일
- preview: 통합 검증 정보
- production: 최소 구조 로그와 오류 지표
- 운영 debug 기본 비활성
- URL 파라미터만으로 민감한 진단 모드 활성화 금지

## 8. 오류 경계

앱 전체, 주요 편집 화면, Canvas, 관리자 데이터, 시안공간에 적절한 오류 경계를 둔다. 일부 패널 실패가 전체 흰 화면으로 번지지 않게 하되 데이터 불완전 상태의 저장·게시은 차단한다.

## 9. 필수 관측 항목

- 페이지 로드와 처리되지 않은 예외
- 관리자 인증 실패율
- 데이터 로드·저장 실패율
- 업로드·게시 실패율
- 시안 복호화 실패율
- 주문 생성 실패율
- Canvas export 실패
- 앱 버전과 배포 커밋
- 브라우저·OS 범주
- 핵심 성능 지표

개인 사용자 추적보다 장애 진단을 우선한다.

## 10. 긴급 확인 조건

- 운영 페이지 로드 불가
- 관리자 저장 연속 실패
- 데이터 손실 가능성
- 주문·시안 링크 실패 증가
- 인증·Rules 오류 급증
- 이미지·인쇄 출력 실패
- 배포 직후 오류 급증

## 11. 외부 오류 수집 도구

특정 서비스 도입은 별도 스펙으로 결정한다. 도입 시 개인정보 필터, URL 토큰 제거, request body·상태·이미지 전송 차단, 환경 분리, source map 통제, 보관 기간을 먼저 확정한다.

## 12. 필수 테스트

- 오류 카테고리 매핑
- 민감정보 로그 제거
- 타임아웃과 제한 재시도
- 중복 요청 방지
- 오류 경계 fallback
- 실패 시 성공 표시 금지
- correlation ID 표시
- 처리되지 않은 Promise rejection 0건
- 오프라인 데이터 보존
