# 결정: Modern Studio 카라멜 앰버 팔레트

결정일: 2026-07-21

상태: **확정 · 코드/테스트/PNG 반영 대기**

## 핵심 결정

Modern Studio(B)의 포인트 팔레트를 기존 테라코타에서 **카라멜 앰버**로 교체한다.

| 토큰 | 확정값 |
|---|---|
| `accent` | `#B0894E` |
| `accent-2` | `#C6A46B` |
| `accent-soft` | `#F2E9DA` |
| `kakao` | `#FEE500` 유지 |

이 결정은 기존 테라코타 `#C0614A` / `#D8846F` / `#F6E6E1`보다 우선한다.

## 현재 반영 상태

- 이 결정서, `CLAUDE.md`, 리빌드 인덱스와 디자인 텍스트 기준에는 반영한다.
- 현재 POC 코드·테스트·자동검증 결과는 기존 테라코타로 생성된 역사적 상태이므로 스펙 002 확대 접근성 수정과 섞어 변경하지 않는다.
- `docs/rebuild/design/*-B.png` 4종은 현재 저장소에서 기존 테라코타 버전이다. 카라멜 앰버 재렌더본은 과거 작업에서 유실됐으며 별도 색상 반영 작업에서 다시 생성·검증한다.
- 과거 스펙·리뷰·결과 문서의 테라코타 수치는 당시 검증 근거로 보존하되, 최신 디자인 결정으로 사용하지 않는다.

## 접근성 미확정 항목

- `accent` 위 텍스트 색은 아직 확정하지 않는다.
- `#B0894E`와 흰색·기본 ink 조합의 WCAG 명암비를 별도 색상 반영 스펙에서 계산한다.
- 일반 텍스트 4.5:1, 큰 텍스트·UI 3:1 기준을 충족하지 않는 조합은 사용하지 않는다.
- 명암비 계산 전 `accent-ink:#FFFFFF`를 최신 확정값으로 간주하지 않는다.

## 적용 순서

1. 스펙 002 모바일 확대 접근성 결함을 독립 커밋으로 해결·재검증한다.
2. 다음 별도 스펙에서 문서·POC 토큰·테스트·결과 설명·시안 PNG를 카라멜 앰버로 일괄 반영한다.
3. 명암비와 대표 실기기 색상 표시를 검증한다.
4. 그 뒤 Tailwind와 전체 기술 스택을 최종 확정한다.

## 금지

- 스펙 002 구현 커밋에 색상 변경을 혼합하지 않는다.
- 일부 문서나 한 토큰만 먼저 바꾸지 않는다.
- 기존 POC 명암비 결과를 새 팔레트 결과처럼 재사용하지 않는다.
- 과거 테라코타 PNG를 카라멜 앰버 시안이라고 표기하지 않는다.
