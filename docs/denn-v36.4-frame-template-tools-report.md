## 수정사항 3 결과

- 여러 장 업로드 가능
- 개별 표시/숨김
- 개별 투명도 조절
- 개별 삭제
- 관리자 상세설정 화면에서만 DOM 오버레이로 표시
- 고객 목업툴, 시안 저장, 주문 이미지에는 포함하지 않음

## 새로 추가한 필드

- `templateBackgroundColor`: 템플릿 배경색
- `editorOverlayImages`: 관리자 상세설정 전용 작업 가이드 이미지 목록

## 고객 렌더 제외 필드

- `editorOverlayImages`

`editorOverlayImages`는 관리자 상세설정에서 위치 맞춤용으로만 사용하며, 고객 목업툴 렌더와 시안 저장 이미지에는 사용하지 않는다.

## 안정화한 문제

- 액자템플릿 목록 필터는 기존 렌더 함수를 갈아엎지 않고 후처리 방식으로 적용해 기존 수정/상세설정 버튼 연결을 보존했다.
- 배경색은 `dataUrl` 합성이 아니라 별도 필드로 저장해 투명 PNG alpha를 보존했다.
- 상세설정 가이드 이미지는 최종 캔버스에 굽지 않고 DOM 오버레이로 분리해 고객 렌더 유입 위험을 줄였다.

- 상세설정 가이드 이미지는 DOM 오버레이 방식이라, 매우 높은 확대율/스크롤 상태에서는 캔버스 위치 계산 보정이 추가로 필요할 수 있다.

- 실제 UI 클릭 검증은 브라우저 연결 가능 상태에서 한 번 더 확인하는 것이 좋다.
